# software-testing-learning-roadmap

零基础软件测试学习路线与 Pytest、Playwright、接口测试、SQL 实践资料。

## 🎮 游戏化学习入口

打开 [TestQuest 学习任务大厅](./game/index.html)，每天完成一个任务，获得 XP、升级并解锁徽章。

> 如果部署了 GitHub Pages，也可以访问：`https://respect3227.github.io/software-testing-learning-roadmap/game/`

## 学习内容

- 测试基础、用例设计和 Bug 报告
- Python 与 pytest
- 接口测试、接口文档和 requests
- SQL 与数据验证
- Playwright UI 自动化
- Page Object Model
- Git / GitHub 与作品集

完整路线见 [`docs/BEGINNER_TESTING_ROADMAP.md`](./docs/BEGINNER_TESTING_ROADMAP.md)。

## 本地启动任务网站

直接用浏览器打开 `game/index.html`，或者运行：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000/game/>。

学习进度目前保存在浏览器的 `localStorage` 中，不需要登录。后续可扩展为 GitHub Pages、云端同步、账号系统和排行榜。
