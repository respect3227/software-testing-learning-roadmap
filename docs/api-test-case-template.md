## 结果分析

如果用例失败，先判断：

1. 请求是否发送成功？
2. URL、方法和参数是否正确？
3. 服务是否可用？
4. 认证是否有效？
5. 实际响应是否符合接口文档？
6. 测试断言是否写错？
7. 是否需要提交 Bug？
