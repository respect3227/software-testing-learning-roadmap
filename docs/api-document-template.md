## 2. 请求信息

### Headers

| 名称 | 类型 | 必填 | 示例 | 说明 |
|---|---|---|---|---|
| Content-Type | string | 是 | application/json | 请求格式 |
| Authorization | string | 否 | Bearer <token> | 登录凭证 |

### Path 参数

| 参数 | 类型 | 必填 | 示例 | 说明 |
|---|---|---|---|---|
| id | integer | 否 | 1 | 资源 ID |

### Query 参数

| 参数 | 类型 | 必填 | 示例 | 说明 |
|---|---|---|---|---|
| keyword | string | 否 | 汉绣 | 搜索关键词 |
| page | integer | 否 | 1 | 页码，从 1 开始 |
| page_size | integer | 否 | 10 | 每页数量 |

### Body 示例

```json
{
  "name": "测试项目",
  "category_id": 1
}
```

## 3. 响应信息

### 成功响应

- HTTP 状态码：`200`
- Content-Type：`application/json`

```json
{
  "code": 0,
  "message": "success",
  "data": []
}
```

### 失败响应

| 场景 | 状态码 | 错误码 | 错误信息 |
|---|---:|---|---|
| 参数缺失 | 400 | | |
| 未登录 | 401 | | |
| 无权限 | 403 | | |
| 资源不存在 | 404 | | |
| 服务异常 | 500 | | |

## 4. 字段说明

| 字段 | 类型 | 必返 | 示例 | 说明 |
|---|---|---|---|---|
| code | integer | 是 | 0 | 业务状态码 |
| message | string | 是 | success | 提示信息 |
| data | array/object | 是 | [] | 业务数据 |
