# 学习清单：从零基础到测试岗位

这个清单帮助你在实习和校招前有一个完整的技术路线。

## 一、基础学习阶段

- [ ] 软件测试基础
- [ ] 测试用例设计
- [ ] Bug 报告书写
- [ ] Python 入门
- [ ] pytest 基础
- [ ] Playwright 基础

## 二、进阶学习阶段

- [ ] 接口测试
- [ ] SQL 基础
- [ ] Git 与 GitHub
- [ ] 失败排查和日志分析
- [ ] Page Object Model
- [ ] HTML 报告和截图处理

## 三、实践提升阶段

- [ ] 自己整理一个测试项目
- [ ] 至少完成 1 份测试用例文档
- [ ] 至少完成 3 个规范 Bug
- [ ] 完成 1 套 smoke 测试
- [ ] 结合接口测试和 UI 测试完成完整流程
- [ ] 完成 GitHub 可展示作品集

## 四、面试准备阶段

- [ ] 能讲清楚测试流程
- [ ] 能解释 pytest fixture
- [ ] 能解释 Playwright 自动等待和断言
- [ ] 能说明 Page Object Model 的好处
- [ ] 能说清楚接口测试和 UI 测试差别
- [ ] 能讲清楚 SQL 中最常用的查询语句
- [ ] 能讲清楚 Git 提交和 PR 过程

## 五、推荐顺序

```text
测试基础 -> Python -> pytest -> Playwright -> 接口测试 -> SQL -> Git -> CI/CD
```

如果你能把这些点逐步完成，实习期和校招前的技术储备会明显增强。
